# Upstream license fallback

The pyserial 3.5 wheel in some environments omits the complete license file. `pyserial-LICENSE.txt` is retained unmodified from the matching upstream v3.5 release:

https://raw.githubusercontent.com/pyserial/pyserial/v3.5/LICENSE.txt

This is a third-party component license, not a license added to the application.

The PortAudio native-library license is retained from the official v19.7.0 release. The Windows binary supplier also identifies Ross Bencina and Phil Burk / MIT in its bundled README:

https://raw.githubusercontent.com/PortAudio/portaudio/v19.7.0/LICENSE.txt
