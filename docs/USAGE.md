# 使用说明

## 1. 安装与启动

本说明使用 Windows PowerShell，建议 Python 3.11。在项目根目录运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe motion_studio.py examples/demo.vskproj
```

这些命令直接调用虚拟环境中的 Python，不要求先激活环境。也可以运行 `Motion-Studio.ps1 -Setup` 安装基本依赖，再用 `Motion-Studio.cmd` 启动；`Motion-Studio.ps1 -Check` 可检查运行环境，`-Console` 保留控制台输出以便排查错误。

基础依赖用于示例播放、动作演示、编排、保存、LRC 与渲染。音频播放使用系统默认输出设备，程序不采集麦克风。

### FFmpeg

新歌曲解码和 MP4 导出使用 FFmpeg。安装后，确保命令行可以运行：

```powershell
ffmpeg -version
```

也可以为当前 PowerShell 会话设置 `VINYL_FFMPEG`，值为本机 `ffmpeg` 可执行文件的完整路径。程序通过参数列表调用编码器，不需要手工拼接歌曲文件名。

### 歌曲分析依赖

若要导入新的 MP3 等音频，另外运行：

```powershell
.\.venv\Scripts\python.exe -m pip install torch==2.6.0 torchaudio==2.6.0 --index-url https://download.pytorch.org/whl/cpu
.\.venv\Scripts\python.exe -m pip install -r requirements-analysis.txt
.\.venv\Scripts\python.exe import_music.py prepare-model
```

或者运行 `.\importer\Setup-Importer.ps1` 一次完成环境准备。需要先安装依赖、稍后再下载模型时，可使用 `-SkipModelDownload`。

首次准备 Beat This! 节拍模型需要下载权重。之后使用本机缓存；不要将模型缓存提交到自己的工程仓库。

### 可选人声句尾识别

有 LRC 时直接导入歌词即可。没有 LRC、希望尝试识别人声句尾时，安装 `requirements-lyrics.txt` 并在界面中主动选择识别。首次使用会下载语音模型，耗时取决于环境与歌曲长度；识别结果仍需试听。

## 2. 导入歌曲和歌词

点击顶部 **导入歌曲…**，选择音频文件。支持 MP3、WAV、M4A、FLAC、OGG、AAC、WMA；当前工程格式接受 4 秒到 30 分钟的音频。

同一窗口可以选择一份可选 LRC。同目录同名歌词会自动带入，也可以更换、清空，或者先导入歌曲再点顶部 **导入歌词（LRC）**。

导入过程中会显示当前处理阶段、活动进度和已用时间。模型初始化等阶段没有准确的完成百分比，界面会显示进行中的活动条。

歌曲转换为工程使用的 16 kHz、单声道、PCM16 音频。节拍、鼓点和音量决定自动动作计划与反应轨道；复杂伴奏、弱拍与变速段可能需要人工修正。

## 3. 演示和编排动作

左侧动作库可按级别筛选，也可以搜索中文名、英文名或脚法。点击一项会静音循环演示该完整动作，演示速度可选 80、100、120、150 BPM。点击 **返回编排** 或播放歌曲返回音乐时间轴。

将动作拖到下方时间线，落点会吸附到分析拍点。选中动作后可以：

- 拖动整块动作，移动到另一拍。
- 拖动右侧边缘，调整到该动作允许的完整拍数。
- 在右侧填写起始拍与时长，再点 **应用设置**。
- 删除、撤销或重做；空白区由滑行片段衔接。
- 点 **整理衔接**，更新动作之间的过渡安排。

编辑以完整动作片段为单位。重叠可能替换整段动作，可用撤销恢复。鼓点抬脚、身体律动和轨迹变化是预制动作与音乐特征的组合，不是实时训练出的新动作。

### 为什么是 52 套动作

共享动作表保留 55 个编号，以维持旧工程和歌曲包兼容。其中“低滑下压”“舒展摆臂”“前后轮摆转”已停用，动作库显示 52 套可用动作。打开含停用动作的旧工程时会提示替换为滑行衔接，应另存更新后的工程。

## 4. 人物、场景与轨迹

右侧可分别选择人物、背景主题、唱片颜色和脚边特效；单独调整外观不会换歌或重置播放进度。

人物包括澄音、凛、绮星与霓虹 Neon。背景包括日落迪斯科、午夜霓虹、奶油胶片、雪山晨曦、萤光森林和雷雨风暴。手动唱片颜色有曜石黑、葡萄酒紫、深海蓝和琥珀棕。

脚边特效可选自动搭配、关闭、蓝黄闪电、熔金火花、冰晶星屑、星环波纹、能量流焰。“关闭”关闭额外脚边特效，仍保留滑行轨迹和落地四溅。

轨迹和特效随动作、触地状态及音量变化。人物的头发与衣摆按动作进度计算摆动；暂停或拖动时仍可定位同一画面。

## 5. 歌词与自动切场景

导入 LRC 后，当前一句歌词显示在预览底部，跟随实际音乐位置切换。播放栏的 **显示歌词** 控制字幕可见性，隐藏不会删除歌词时间轴。增强 LRC 的逐字时间标签不会产生逐字卡拉 OK 效果。

“自动切场景”有四种模式：

| 模式 | 切换时机 |
| --- | --- |
| 关闭 | 保持手动选择的外观 |
| 每 2 秒 | 按音乐进度每两秒切换 |
| 歌词句首 | 到达每条非空 LRC 歌词原始时间戳时切换 |
| 歌词句尾 | 按句尾表中的候选或手工时间点切换 |

自动模式会让场景、唱片和中心纸标使用同色系；勾选 **同步换人物** 后角色也跟着轮换。暂停、前后拖动与循环都使用同一条音乐时间轴。

歌词句首支持 0 秒时间戳。同一时间的多行只触发一次，带时间的空白行只清空字幕，不触发场景切换。没有可用歌词时，句首模式会提示导入，不会改用两秒计时器。

普通 LRC 往往只有句首。需要“唱完一句再切换”时，打开 **句尾时间点…**，试听候选、导入或手工增加时间点，再微调。仅靠停顿估算无法保证区分人声与乐器停顿，持续伴奏和纯音乐也可能没有可靠候选。

## 6. 全屏观看

点击 **全屏预览**、双击预览画面或按 **F11** 进入全屏。画面等比放大，字幕与音乐进度保留；底部可播放、暂停或拖动定位。按 **Esc** 或“退出全屏”返回，播放位置保持。

预览显示速度取决于电脑、窗口大小和场景负载。后台只保留最新待渲染请求，播放进度不等待渲染队列追帧。

## 7. 导出带音乐的 MP4

点击顶部 **导出动画…**：

1. 选择 `.mp4` 保存位置，默认保存在项目的 `exports/` 目录。
2. 选择整首歌曲，或填写片段开始和结束秒数。
3. 选择 480、960、1080 方形画面，以及 24 或 30 fps。
4. 选择是否包含音乐、是否叠加歌词。
5. 点击 **开始导出**，完成后可打开输出文件夹。

导出包含当前编排的人物、动作、自动场景、唱片、轨迹和脚边特效。片段导出仍以原歌曲时间定位歌词和场景，不会把片段起点当作歌曲零点。

视频由独立渲染器离线逐帧生成，编码为 H.264 / MP4；选中音乐时写入 AAC 音轨。音轨来自当前工程 PCM，不会重新取原始 MP3 的立体声音轨。960 和 1080 是 480 原始画面的放大，不增加模型细节。

导出进度显示已生成帧数、百分比与耗时。点击 **取消导出** 会停止编码并清理临时结果；只有视频完整生成后才替换目标文件。片段长度至少需要一帧。导出的是当前歌曲编排，动作库的静音演示需先拖入编排再导出。

## 8. 保存、移动和分享工程

点击 **保存编排** 保存为 `.vskproj`。工程旁会保存一份带校验信息的 WAV；移动或分享时请将工程与配套 WAV 一起复制，保留它们的相对位置。

工程保存动作摆放、分析信息、背景、唱片、特效、歌词可见性与自动场景模式。当前手动选择的人物沿用工作台选择；同步换人物的设置随工程保存。

本地工作文件、导出视频、模型缓存与导入歌曲应留在被 Git 忽略的工作目录中。需要向他人分享歌曲或歌词时，请确认相应素材可以分发。

## 环境变量与本地目录

| 名称或目录 | 作用 |
| --- | --- |
| `VINYL_FFMPEG` | FFmpeg 可执行文件路径；未设置时从 PATH 查找 |
| `MOSAICO_STUDIO_PYTHON` | Windows 启动器使用的 Python 可执行文件路径 |
| `MOSAICO_MODEL_CACHE` | 可选模型缓存根目录，默认是用户主目录下的 `.cache/mosaico-vinyl-skater/` |
| `MOSAICO_WHISPER_MODEL` | Whisper `base.pt` 所在目录，优先于通用缓存设置 |
| `TORCH_HOME` | 已明确设置时保留该 PyTorch 缓存位置 |
| `MOSAICO_EXPECTED_DEVICE_MAC` | 使用设备歌曲传输功能时指定目标设备身份；未配置时不会打开串口传输 |
| `projects/analysed/` | 导入歌曲的分析结果与中间文件 |
| `exports/` | 默认动画导出位置 |

这些工作目录、模型权重和个人音频均不属于需要提交的源码。当前仓库不提供设备固件发布；保留的传输入口还会检查目标设备身份、协议与能力。

## 10. 常见问题

**启动时缺少模块：** 确认安装依赖与启动使用同一份虚拟环境中的 Python。运行 `Motion-Studio.ps1 -Check` 检查依赖。

**歌曲导入失败：** 检查 FFmpeg 是否可调用、节拍分析依赖和模型是否准备好，以及歌曲时长是否在允许范围。较长的首次模型初始化可以先看处理阶段与已用时。

**没有声音：** 检查系统默认输出设备。程序根据声卡播放时钟定位动作，无法打开音频输出时会给出错误，不会用假播放进度替代声音。

**歌词不显示或句首模式不切换：** 先导入对应 LRC，再检查“显示歌词”和自动模式。动作库静音演示会隐藏歌曲歌词；点击“返回编排”后恢复。

**导出提示找不到 FFmpeg：** 将 FFmpeg 加入 PATH，或设置 `VINYL_FFMPEG` 后重新启动程序。

**导出看起来不如原视频清晰：** 项目的原始画面是 480 × 480，放大选项只调整输出尺寸。导出帧率是文件的固定帧率，不能作为硬件屏幕刷新率。
