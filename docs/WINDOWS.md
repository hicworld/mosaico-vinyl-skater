# Windows 便携版

Windows x64 便携包通过 [GitHub Releases](https://github.com/hicworld/mosaico-vinyl-skater/releases) 提供。使用发行包不需要安装 Python，也不需要运行源码安装脚本。

## 下载与启动

1. 进入 Releases，打开对应版本。
2. 在 **Assets** 中下载名称含 `windows-x64` 的 ZIP。
3. 将 ZIP **完整解压**到有写入权限的文件夹。
4. 双击 `Mosaico-Vinyl-Skater.exe`。
5. 先播放随附的原创合成示例，再导入自己的歌曲和 LRC。

请保留 EXE 旁的 `_internal` 以及发行包中的其他文件夹。便携版使用完整目录结构，移动程序时应一起移动整个文件夹。

## 发行包组件

完整包包含桌面编排台所需的 Python 运行时、C/WASM 渲染器、原创示例、FFmpeg，以及节拍与人声识别使用的模型。内置组件的具体版本和文件哈希以对应 Release 的清单为准。

已有 LRC 时，直接使用“导入歌词（LRC）”。从人声估算句尾是单独选项，处理时间更长，结果仍可试听微调。

Windows 发行包针对电脑端编排、预览与视频导出，不包含设备固件或应用平台。

## 常用操作

- **导入歌曲**：选择音频，可同时选择 LRC；处理过程中显示阶段与已用时间。
- **编排动作**：点击左侧动作看演示，拖入下方时间线后调整起始拍和完整动作时长。
- **全屏预览**：点击预览区按钮、双击画面或按 F11；Esc 返回，空格播放／暂停。
- **歌词与切换**：可开关歌词，并选择每两秒、歌词句首或歌词句尾切场景；可同步更换人物。
- **保存编排**：保存为 `.vskproj`，保留旁边的配套 WAV。
- **导出动画**：顶部“导出动画…”可生成带音乐的 MP4，支持整首或指定片段、可选歌词、进度与取消。

详细操作见 [使用说明](USAGE.md)。

## 文件保存位置

便携包默认将用户文件放在 EXE 所在文件夹：

```text
projects/       歌曲分析与编排相关文件
exports/        默认动画导出目录
logs/           启动错误日志
```

导出对话框也允许自行选择视频保存位置。

如果 EXE 所在文件夹无法写入，程序改用：

```text
%LOCALAPPDATA%/MosaicoVinylSkater/
```

该目录下同样使用 `projects`、`exports`、`logs` 子目录。启动错误日志为 `logs/motion-studio-error.log`。

需要固定数据位置时，可在启动前设置 `MOSAICO_DATA_DIR` 环境变量。显式指定的目录必须可写；配置错误时程序会提示，不会悄悄切换到别处。

## 更新与迁移

更新前先保存当前编排。将新版本完整解压到新文件夹，再用“打开编排”载入已有工程。

分享或迁移工程时，一起复制 `.vskproj` 和它引用的同目录 WAV；只复制工程 JSON 不能带走音频。便携包中的原创示例可以随时重新打开。

## 排查问题

### 双击后没有出现界面

先检查是否完整解压，EXE 与 `_internal` 是否仍在同一发行目录。若生成了 `logs/motion-studio-error.log`，可根据日志定位启动原因；受限目录的日志在上述用户数据目录内。

### 音乐没有声音

检查 Windows 当前输出设备、音量与扬声器连接，再重新播放。编排台使用当前系统音频输出，不需要麦克风权限。

### 歌词没有显示

为当前歌曲导入对应 LRC，并勾选“显示歌词”。导出时使用“叠加歌词”选项。示例配乐是合成器乐，随附文字用于展示时间轴。

### 导出很慢

导出逐帧生成动画。片段长度、画面尺寸和电脑 CPU 都会影响用时，进度条会显示实际已生成帧数；可取消后缩短片段或选择 480 × 480。
